# Mehmet Furkan Ketme

Bursa Teknik Üniversitesi'nde Mekatronik Mühendisliği yüksek lisansı yapıyorum.
Mobil robotların algılama ve karar verme tarafı üzerine çalışıyorum: derin
pekiştirmeli öğrenme ile navigasyon, tek kameradan 3B konum kestirimi ve
ROS 2 üzerinde çalışan otonom mobil robotlar.

### Yayınlar

- M. F. Ketme, O. Mısır, "Calibration-Based Two-Stage Monocular Approximate
  3D Object Localization on KITTI Using Depth Anything V2 and YOLOv8," ASYU 2026.

### Projeler

- **[ddqnlabirent](https://github.com/mfurkanketme/ddqnlabirent):** Dinamik
  koridor ve labirent ortamlarında DDQN ile mobil robot navigasyonu. Curriculum
  learning, güvenlik kalkanı, bulanık kontrolcü ile karşılaştırma ve ablation.
- **SIRIUS AMR:** PUSULA takımının TEKNOFEST 2026 Sanayide Robotik Uygulamalar
  yarışması için geliştirdiği otonom mobil robot. Takım kaptanı; ROS 2, Nav2,
  LiDAR, IMU ve enkoder ile navigasyon.

### Araçlar

Python · PyTorch · ROS 2 (Humble, Jazzy) · Nav2 · Gazebo · YOLOv8 · OpenCV · Linux
